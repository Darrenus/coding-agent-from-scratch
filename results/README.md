# 实验原始数据

每次对照实验把**每一次运行的完整记录**存在这里，而不只是汇总统计。

这么做的理由来自一次教训：模块 2 的第一版实验只打印了平均值，等到想追问
「贵的那几次工具序列长什么样」时，原始数据已经没了，只能重新花钱跑一遍。

> **你下一步想问的问题，永远不是设计实验时预想的那个问题。**
> 存储很便宜，重跑很贵。

| 文件 | 来自 | 内容 |
|---|---|---|
| `results-*.json` | `experiment.py` | 工具描述对照实验：每次运行的工具序列、步数、token |
| `edits-*.json` | `edit_experiment.py` | 编辑策略实验：每次 `edit_file` 调用的完整参数与命中的匹配策略 |

README 里引用的每个数字都能从这些文件重新算出来。
